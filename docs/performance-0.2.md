# 0.2 最终 Windows 构建性能实测

三本用户 EPUB 的稳态私有内存明显下降；空白窗口基本相当，轻型 PDF 私有内存略降。最终版正文使用完整客户区，比旧版保留上下栏时的排版面积更大，以下是产品版本对照，不是等面积引擎微基准。仍不宣称 G5 全项通过。

## 机器、构建与测量

2026-10-26，Core i9-14900HX（24 核/32 逻辑处理器），Windows 11 家庭版中文版 10.0.26200，实际 150% DPI，默认 1180×840 逻辑像素窗口。测试在当前桌面执行，未隔离后台应用、未禁用杀毒、未清空 OS 缓存或裁剪工作集；物理存储型号和完整后台负载未标准化。

构建 SHA256：

- production: `8fbe2148fb58c9f5a31a159a70ab99c7d9f700174303e9305ce17d0b14618a2c`
- qa: `ed7e4f1f5031031ef206694948d73a1f0844ce6198d305e89d703e91d9dacade`
- baseline: `386f8f97ff1f57a1952680c32be801422a6cf4611bf32ccd09c133436980f75e`

旧版 EXE 是原已发行的 v0.1.0-preview.1。生产版由外部 Win32 采样器测量，没有 QA 计时器；每次 8 秒，取第 3–8 秒各采样点的中位数，再取 3 次进程运行的中位数。只终止采样器自己启动的子进程，不操作用户保留的两个窗口；强制结束不作为正常退出证明。

最初跨时段对照出现空白约 +0.6 MiB，随后在当前桌面完整重测旧版 24 次。当前旧版空白也接近 14.1 MiB，故不能把早先差值全归因于 UI；没有证据精确拆分外部辅助组件与系统状态的成本。本文使用后一次完整对照，[先前对照](evidence/iteration-0.2/earlier-baseline-memory.json)亦保留，未丢弃不利数据。

## CPU、压力与退出

44 次生产进程观测中，每个约 4.8 秒区间的 CPU 时间增量为 0–125ms，折合单核 0–2.588%，按 32 个逻辑处理器归一化约 0–0.081%。计数粒度为 15.625ms，记录为 0ms 不代表无限精度的零 CPU。

代码没有生产诊断轮询或固定帧率循环，悬停只更新浮层可见性。控件事件与系统/辅助客户端活动可能产生 CPU 工作；本次桌面未隔离，不能把采样的每个差异归因于新增界面。

730 项压力操作为 500 次翻页、100 次字号变化、100 次尺寸变化和 30 次切书，重复使用两份原创样本，错误 0；不是 30 本不同书。应用缓存峰值约 15.65 MiB（16,411,520 B），起止句柄 239→241、Private 约 26.86→25.81 MiB，未见持续线性增长；短程观察不是长时无泄漏证明。14 项浮层与控件检查单列。详见 [window-scenarios.json](evidence/iteration-0.2/window-scenarios.json)。

原生 worker 正常关闭后的独占文件重开、并发取消与资源释放有回归；窗口 QA 正常退出。用户打开的实例刻意保留，不能把桌面上仍存在的用户窗口当作测试残余，也不宣称已完成完整系统退出审计。
