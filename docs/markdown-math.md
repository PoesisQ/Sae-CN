# Markdown 数学公式

使用 `$...$` 写行内公式，`$$...$$` 写独立公式，也可以使用明确标为 `math` 的围栏块：

````markdown
膜电位 $u_{\mathrm{rest}}$ 和电容电流 $I_C=C\frac{du}{dt}$。

$$
\tau\frac{du}{dt}=-(u-u_{\mathrm{rest}})+RI(t)
$$

```math
\begin{pmatrix}1&2\\3&4\end{pmatrix}
```
````

原文中普通文字 `u_rest`、反引号里的 `I_C`、未标为 `math` 的代码块保持原义，不猜测或改写为公式。
货币美元符号可写为 `\$`，需要展示公式源码时使用代码块。

当前覆盖常见分式、上下标、根式、希腊字母、求和/积分、括号、矩阵及 `aligned` 对齐组。
这是有界的原生数学排版子集，不是完整 TeX/MathJax。自定义宏、带线数组、组合否定、负间距和部分局部样式命令会显示保留的公式源码，并在文档信息中提示数量；不静默删去公式。显式数学字号变体、复杂重音和运算符细节仍可能有排版差异。
不支持完整 TeX 文档、外部宏包、自动公式编号或 `\(...\)` / `\[...\]` 分隔符。
超长公式按页宽等比缩小，单个多行公式块不能跨页拆分。常规公式在页底放不下时移至下一页，保持字号；不会为了挤入剩余高度而额外缩小。

公式通过 [pulldown-latex 0.8.0](https://docs.rs/pulldown-latex/0.8.0/pulldown_latex/) 的纯 Rust 解析器生成 MathML，
再用 Rust 计算布局，以 SVG 矢量文字和几何图形交给现有 MuPDF 绘制。
数学字体来自 Windows 的 Cambria Math 和 Times New Roman，只读映射、按需载入，不随程序分发。
完整依赖源码保留解析器上游附带的示例 WOFF2 字体及对应 GUST/LPPL 许可；Windows 运行包不包含或加载这些字体资产。
文字保留原生选字及搜索坐标；根号和分数线等图形没有对应的可搜索文字。特殊数学字母可能保留其 Unicode 字形编码。

普通文档不初始化公式排版器；解析器、MathML 树和排版中间数据在转换完成后释放。
不增加浏览器、JavaScript 引擎、辅助转换进程、常驻索引或计时器；继续共用现有页面缓存和渲染线程。
每个公式最多 8 KiB、4096 个解析事件、32 层布局；每份 Markdown 最多处理 1024 个公式，生成公式标记总量最多 8 MiB。
超过范围或无法完整表示时保留源码。Markdown 原文件始终只读。

本轮按用户要求不打开或操作桌面窗口，使用真实 Windows 原生引擎的离屏页面、字形坐标和无窗口内存测量验证；
这些记录不代替窗口首帧、空闲 CPU、不同桌面 DPI 的交互验收。
实测数字及离屏示例见 [本轮记录](iteration-0.4.1.md)。
