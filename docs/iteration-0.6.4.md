# Sae Reader v0.6.4-preview.1

## 玻璃拨轮

常规宽度的窗口里，停在工具栏上的拨轮半径从 62 增至 82 个逻辑像素，悬停时增至 100。两侧的名称有足够的弧长，刻度随挡位转动，读数指针留在底部。小窗口会按工具栏可用宽度收窄。

![同一只原生拨轮在静止、展开及夜读时的表现](evidence/iteration-0.6.4/view-wheel.png)

玻璃会透出本页的颜色和轮廓。看上图蓝色校样的浅色条带，它在轮缘处稍稍转向，平行细线则在进入磨砂区域后变柔。左上方的亮面、沿圆弧收窄的高光和短接触阴影共用一个光照方向。这处材质参考了苹果对控件折射和文字辨识度的处理。[Apple 的材质设计演示](https://developer.apple.com/videos/play/wwdc2025/219/)

实现沿用 Rust、Slint 软件渲染和 MuPDF。拨轮读取已渲染书页的共享 RGB 像素，把自身覆盖区域采到小网格上，做两次一维滤波，再画出边缘折射和高光。最大的轮面纹理为 318 × 159 像素，占 197.5 KiB。换页、换色或变更大小时才需要新的取样，轮面上的字和刻度可以独立转动。

## 全幅封面

两种动画都延伸至窗口四边。「Sae」直接叠在画面上，从字形实际笔画下方取样。亮度越过不同的进、出阈值才换墨，颗粒和短时的明暗变化不会反复触发。字形有一条窄的反色轮廓，用来保住穿过明暗交界的细笔画。

![Plasma 与 Blue Grain 的原生首页实拍](evidence/iteration-0.6.4/covers.png)

本机逐像素对照同一帧的动画输入。在十张不同窗口尺寸、缩放和封面状态的截图中，旧纸色面积均为 0%。两张 1770 × 1260 动态截图的笔画对比度中位数分别是 20.18∶1 和 6.89∶1。直接打开文件跳过首页，选书后释放动画。原有朱红版画与上一版同尺寸截图逐像素一致。

## Windows 实测

同一台四核 Windows Server 2022 上，新旧版各交替热启动十次，记录原生窗口可截图的时间。另用两版发行 EXE 各开三个六秒窗口，取进程私有内存的中位数。打开文档的测量使用仓库里的 PDF 和复杂 EPUB 校样。

| 场景 | 0.6.3 首帧中位数 | 0.6.4 首帧中位数 | 0.6.3 私有内存 | 0.6.4 私有内存 |
| --- | ---: | ---: | ---: | ---: |
| 动态首页 | 57.26 ms | 54.75 ms | 11.38 MiB | 11.77 MiB |
| PDF | 152.36 ms | 151.02 ms | 12.61 MiB | 12.61 MiB |
| 复杂 EPUB | 149.61 ms | 150.56 ms | 11.34 MiB | 11.33 MiB |

PDF 首帧的第 95 百分位由 154.60 ms 变为 162.06 ms。这组短测中，新旧版的文档首帧中位数接近。发行 EXE 为 25,887,232 字节，增加 21 KiB。

- **拨轮**。100%、150%、200% 缩放下，局部玻璃纹理的平均生成时间分别为 0.65、1.20、1.16 ms。两次对照里，PDF 拨轮展开相对隐藏平均多占 0.44 MiB 私有内存。展开并停住后三秒，两次进程 CPU 时间增量均为 0 ms。三个缩放比例下的额外纹理重建次数也都是 0。150% 的校样中，细线相邻像素的平均亮度差从玻璃外的 11.29 降至玻璃内的 0.38。
- **首页**。两轮约 4.5 秒的前台采样中，Plasma 动画占单个逻辑核心的 4.85%–5.55%，Blue Grain 为 0.69%–3.81%。两张首页的私有内存中位数分别为 11.76 和 11.66 MiB，较上版分别多 0.37 和 0.40 MiB。最小化后的 2.5 秒采样中，两种动画的进程 CPU 时间增量均为 0。直接打开 PDF 或 EPUB 会跳过这段动画。
- **回归范围**。13 组原生窗口场景覆盖分页、目录、键盘翻页、缩放挡位、不同 DPI、复杂 EPUB 和连续阅读。公式、文本、电子书适配器和 PDF 网格另有 Rust 测试。私藏书目没有上传至测试机，本次没有重新验收这些书。固定安装路径从 0.6.3 升到 0.6.4 的测试在独立 Windows 环境通过。[原始测量](evidence/iteration-0.6.4/windows.json)

## 本地安装

此预览版尚无受信任的 Authenticode 签名。一台启用 Smart App Control 的 Windows 11 拒绝启动该 EXE，系统返回 4551，CodeIntegrity 记录事件 3077。独立 Windows 测试机可以运行相同 SHA-256 的发行文件。安装器会先请求 Windows 创建挂起的进程，核实启动许可，立即结束探测进程。安装后会再检查固定路径。若目标处失败，自动恢复原有程序。遇到同一拦截的用户可以继续使用已获系统许可的旧版。[微软的 Smart App Control 开发说明](https://learn.microsoft.com/windows/apps/develop/smart-app-control/overview)
