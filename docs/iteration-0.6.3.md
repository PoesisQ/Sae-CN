# Sae Reader v0.6.3-preview.1

## 首页纸面

Plasma 与 Blue Grain 使用相同的构图。一条斜边从左边缘落到底边，斜边与镂空字标之间的留白由字标尺寸决定。宽屏上多出的面积交给动画，小窗口中「打开书籍」仍有 44 个逻辑像素高的点击区域。两种效果逐次启动交替出现，首页左右键可切换到另一种动画或朱红版画。

![两张动态首页的原生窗口实拍](evidence/iteration-0.6.3/covers.png)

在 1770 × 1260 的客户区逐像素统计，两种效果的纯纸色面积均由 40.88% 降至 16.56%。同一台机器在 150% 桌面缩放下，960 × 720 小窗口为 18.65%，1920 × 1200 宽窗口为 14.72%。另在 125% 和 200% 界面缩放下逐行检查了斜边的连续性。朱红版画与上一版在相同尺寸下的截图逐像素相同。

## 拨轮的两个止点

PDF 从单页到多页共有两个挡距，EPUB 等可重排格式从单页到双页只有一个挡距。每个挡距分成八小格，首尾以外留白。按住慢拖时，刻线和文字一同经过固定指针。圆弧下面的接触阴影沿轮缘向外渐淡，在实拍工具栏上距轮缘约 5 个逻辑像素处已与底色相同。阴影使用同心的原生细圆边绘制。

![同一只 PDF 拨轮分别停在单页、双页和多页](evidence/iteration-0.6.3/view-wheel.png)

Windows 鼠标输入覆盖两个止点、两个方向和五个中间拖动位置。截图检查了每个预期刻度与两端以外的空白，夜读配色也执行了同样的检查。原有缩放圆盘回放了 14 次手势，共 852 个鼠标采样点。[夜读拨轮实拍](evidence/iteration-0.6.3/view-wheel-dark.png)

## Windows 实测

本机 Windows 11 x64，桌面缩放 150%。两版交替暖启动，每种样本、每个版本各 10 次，计时到原生窗口可取得首屏像素。内存取普通发行程序三轮、每轮六秒中后半段的进程私有字节中位数。

| 样本 | 上一版首屏中位数 | 本版首屏中位数 | 上一版私有内存 | 本版私有内存 |
| --- | ---: | ---: | ---: | ---: |
| 直接启动首页 | 55.58 ms | 54.24 ms | 16.54 MiB | 16.34 MiB |
| 30 页 PDF | 152.18 ms | 149.36 ms | 21.42 MiB | 21.38 MiB |
| 复杂 EPUB | 151.39 ms | 151.31 ms | 18.86 MiB | 18.79 MiB |

另开普通发行程序，在真实 PDF 窗口展开拨轮，通过屏幕取色确认轮面已就位。两轮各静置三秒，进程 CPU 时间增量均为 0 ms，私有内存为 21.49 和 21.53 MiB。两套首页动画播放时单核 CPU 占用中位数均约为 11.4%，私有内存分别为 16.37 和 16.20 MiB。普通发行程序从新位置的「打开书籍」按钮进入 Windows 选书框，实测取消后恢复播放，再次选书可以进入正文。

46 项 Rust 测试、Markdown 公式性能基准和 13 组 Windows 窗口回归通过。EXE 为 25,865,728 字节，较上一版减少 10 KiB。逐次暖启动、内存、CPU 和像素测量均记录在同一份数据中。[原始测量](evidence/iteration-0.6.3/windows.json)
