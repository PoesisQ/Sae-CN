# v0.5.3-preview.1 · 折页与拨盘

![暖纸首页上的书页和书脊](evidence/iteration-0.5.3/home.png)

## 从海报到阅读器

首页取自老式书籍扉页的排法。「Sae」和打开书籍的按钮沿同一条页边线对齐，右侧的书由一组平行四边形构成。每张纸绕同一条斜书脊展开，页间交替露出亮面和背光面。青墨从封面的深绿过渡到翻页边缘的灰白。整幅图为静态矢量，直接打开文件时跳过扉页。[夜读首页](evidence/iteration-0.5.3/home-night.png)

阅读区只在可操作的地方保留这些明暗关系。页码、进度和倍率共用水平中心线。拨盘的外环接光，盘面内收，刻线随手势转动。上移或下移到距边缘 44–72 个逻辑像素的范围就能唤出工具。字体、编码、查找和目录共用同一套面板轮廓，每个转角由两段三次曲线连接，暗边紧贴浮层底面。[底部拨盘](evidence/iteration-0.5.3/pdf-zoom.png) · [夜读拨盘](evidence/iteration-0.5.3/pdf-night.png) · [字体菜单](evidence/iteration-0.5.3/font-menu.png) · [长目录](evidence/iteration-0.5.3/contents.png)

按 Refactoring UI 的层次、邻近和光源原则，首页只保留一个主操作，相关控件共用中心线和边距。42 组实际文字与背景组合涵盖浅色、夜读和打开按钮的静止、悬停、按下状态。最低文字对比度为 4.53∶1。

## 缩放与全屏

- 按住拨盘外圈，顺时针放大、逆时针缩小，可以连续转过十二点位置。按住盘心或紧凑控件上的倍率，可横拖或竖拖。100% 和适宽各有直接入口。拖出面板再松手，面板留在原位，点击正文一次或按 Esc 收起。
- 滑动与转动只在收到输入时计算。拖动时先更新指针和数值，沿用原有的原生渲染合并机制。窗口尺寸变化期间，整页 PDF 用现有页图跟随画布，新的原生像素就绪后替换。点击关闭空查找框也无需向文档线程提交工作。
- Windows 尺寸采样复现了旧版的跳动。点击最大化后，客户区从 2560 × 1494 回到了 1770 × 1260，再进入 2560 × 1600 全屏。原因是旧版在进入全屏前显式请求还原。新版将还原移至退出时，最大化按钮、F11 两条入口均达到显示器尺寸并能回到原有窗口。

## Windows 实测

Windows 11 x64，i9-14900HX，实际显示缩放 150%。旧版为 v0.5.2-preview.1。每个版本、每个样本各做 20 次暖启动，从程序入口计时至原生窗口可取到首屏像素。内存取普通发行 EXE 三轮 6 秒外部采样的稳态私有字节中位数。指定 PDF 和 EPUB 均为仓库原创样本。

| 样本 | 首屏中位数，旧版 → 新版 | 首屏 P95，旧版 → 新版 | 稳态私有内存，旧版 → 新版 |
|---|---:|---:|---:|
| 首页 | 74.30 → 79.82 ms | 94.33 → 98.28 ms | 13.60 → 14.49 MiB |
| PDF | 160.75 → 160.66 ms | 173.43 → 173.21 ms | 21.89 → 21.74 MiB |
| 复杂 EPUB | 159.32 → 171.48 ms | 167.71 → 214.15 ms | 19.28 → 19.07 MiB |

首轮对照中，复杂 EPUB 有一次耗时 660.21 ms。为检查这个波动，又单独做了 20 对启动，每对交替哪个版本先启动。旧版和新版的中位数分别为 165.86 和 163.58 ms，P95 分别为 185.56 和 184.29 ms。这两轮没有显示出稳定的 EPUB 启动时间差。新版九轮短时空闲采样中，八轮 CPU 时间增量为零，一轮首页为 15.625 ms。发行 EXE 为 25,198,592 字节，比上一版增加 91,136 字节。

另用同一本 1156 页实书做双页测试。三次暖启动首屏中位数为 206.52 ms，两轮延长到 12 秒的采样中，稳态私有内存中位数为 29.89 MiB。约 9 秒的空闲区间各消耗 15.625 ms CPU 时间。

真实 Windows 窗口完成了 87 步缩放、111 步键盘导航和 730 次连续阅读操作。连续操作中记录的最高渲染缓存为 15.65 MiB。另检查了目录长标题、字体菜单、查找、页码输入、单页和四页 PDF，以及 100%、125%、150%、200% 显示缩放。虚拟测试比例为 100%、125% 和 200%，本机物理屏幕为 150%。四页窗口缩窄再还原后，四张幻灯片的像素标记回到原位置。

38 项 Rust 测试通过，另单独运行了 Markdown 公式基准。匿名实书读取覆盖 10 份 PDF、5 份 EPUB 和 1 份 AZW3。截图只取自首页和原创测试文档。完整系统冷启动和跨显示器切换仍待验证。[尺寸轨迹、逐次耗时与进程计数](evidence/iteration-0.5.3/windows.json)
