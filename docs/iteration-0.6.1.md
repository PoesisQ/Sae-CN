# Sae Reader v0.6.1-preview.1

## PDF 缩放

上一版用按下的位置决定是否旋转，直拖和转动的起点却常常重叠。现在拨盘在起手时暂存位移，根据弯曲方向和相对圆心的角度识别转动；识别为直拖后沿主轴调节。判定后会把起手位移一起计入倍率，并锁定手势直到松开。整块圆盘共用一次鼠标捕获，点短刻线可以跳至预设，从刻线上按住移动即可调节。快速收起又展开时，刻线在位置稳定后才响应点按。

圆盘与进度条共用一块底板，底板随圆盘上升。刻度环四周都有不透明的面板色，底缘沿用阅读设置的接触阴影。仪表保持正视，倍率始终位于展开圆盘的中心。[浅色缩放盘](evidence/iteration-0.6.1/zoom.png) · [夜读缩放盘](evidence/iteration-0.6.1/zoom-dark.png)

## 视图换挡

顶栏弧面从工具栏下缘的 12 个逻辑像素伸至 56 个。轮缘和工具栏用同一条分段三次曲线连接，交接处斜率和曲率连续。两侧挡位名称根据弧边留出净空，当前挡位停在下方刻度的中心。[展开的三挡视图轮](evidence/iteration-0.6.1/view-wheel.png) · [夜读视图轮](evidence/iteration-0.6.1/view-wheel-dark.png)

每挡拖距为 100 个逻辑像素。过 68 像素的挡点再松手才切换布局，拖到一半松手会回到原挡。越过挡点后需往回拉一段才会退挡，到机械止挡后回拉便能立即移动。鼠标滚轮的单格输入先拨动轮面，连续两格可换一挡。也可直接点击旁边的挡位名称。

## Windows 实测

在 Windows 11 x64（Build 26200）、i9-14900HX、约 64 GiB 内存、NVMe 以及 150% 桌面缩放下测试。发行程序、上一版及实验样本位于同一台机器。下表为交替运行两个版本各 20 次的暖启动，计时从程序入口到原生窗口取得首屏像素。内存另用普通发行程序各启动三轮，每轮采样 6 秒，取稳态私有字节的中位数。表中左侧为 v0.6.0，右侧为 v0.6.1。

| 样本 | 首屏中位数 | 首屏 P95 | 稳态私有内存 |
|---|---:|---:|---:|
| 首页 | 149.73 → 149.25 ms | 156.66 → 157.28 ms | 14.21 → 14.27 MiB |
| 30 页 PDF | 154.06 → 151.84 ms | 158.21 → 158.58 ms | 21.73 → 21.68 MiB |
| 复杂 EPUB | 156.86 → 158.54 ms | 168.78 → 173.01 ms | 19.10 → 19.13 MiB |

同一本 1156 页 PDF 做了双页和八页测试，各启动三次，内存各采样两轮、每轮 12 秒。双页首屏中位数 204.84 ms，私有内存 30.56 MiB。八页分别为 195.85 ms 和 25.50 MiB。发行 EXE 为 25,006,592 字节（23.85 MiB），与上一版相差 +31.0 KiB。三种短样本共九轮空闲采样，约三秒区间内Windows 进程计数器记录的 CPU 时间增量均为 0 ms。该组数据只衡量本机暖启动和短时稳态。

另在同一个发行程序进程中依次停在正文、顶栏换挡轮和底部缩放浮层，每种状态停留 7 秒。新版稳态私有内存依次为 21.84、22.30、22.30 MiB，上版为 21.70、21.91、22.05 MiB。各状态末尾约 3.8 秒内，进程计数器记录的 CPU 时间增量均为 0 ms。

通过 Windows 鼠标输入接口回放 14 次拖动、852 个位置采样。四个方向的直拖中，144 个逻辑像素分别得到 200% 或 50%。从四个象限分别顺转及逆转一圈，从 100% 达到 400% 或 25%。录屏中的 192 帧轨迹按原方向和镜像各回放一次，在可判定的转动样本中，倍率反向次数为零。另检查了单格滚轮回弹、挡点滞回、端点反拖、从刻线起拖、松手继续调节，以及轻拖时文档渲染请求计数。

44 项 Rust 测试通过，另运行了 Markdown 公式基准。13 组窗口回归覆盖 87 步缩放、111 步导航、730 次连续阅读操作和 100% / 125% / 200% 受控显示缩放。连续阅读期间最高页缓存为 15.65 MiB。最大化与 F11 全屏往返通过。兼容性回归读取了本地 10 份 PDF、5 份 EPUB、1 份 AZW3，并单独回测 3 份带脚本引用的静态 EPUB。[逐次测量、倍率和回归结果](evidence/iteration-0.6.1/windows.json)
