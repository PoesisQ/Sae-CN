# 0.2 预览版开发与验收记录 · 2026-10-26

## 本轮完成

- 保持 Rust + Slint + 原生 MuPDF。RGB 页面数据在缓存和界面间共享；字体使用只读映射，应用位图缓存 16 MiB，原生可淘汰资源缓存 32 MiB。取消重复结构化文本克隆，逐章统计分页，限制预取；这些预算不是整进程内存上限。
- PDF 单页、双页按可见区域渲染，支持适页、适宽、放大、滚轮和中键/右键拖动平移。切换尺寸、比例、主题时移除旧位图，同页平移只保留当前切片。原色没有额外颜色处理，选用主题或反色时才调用 MuPDF tint/invert。
- 上下控件改成独立的边缘悬停浮层，阅读画布铺满客户区。浮层、目录、设置和搜索不会缩小正文。新增旋钮滚轮/拖动缩放、释放后提交的进度拖动；移除平移箭头、底部操作提示和打开页标语。窗口级 F11/F10/Esc 和 Ctrl+O/F 避免焦点拦截。
- TXT 严格增量解码并分块转换，保留空行与前导空格；可手动指定编码并按书记忆。Markdown 支持目录、代码、表格、本地图片和链接，原始 HTML 以文本显示；网络与越界资源受限。
- 全文搜索按需扫描，不创建常驻索引或第二份全文。跨章、前后循环、双页右侧命中及缩放后定位有回归。常见 Ruby 和部分 MathML 通过惰性 Rust 适配生成 SVG，原生直接绘制保留文字坐标；相同尺寸固定画布保留出版方绝对定位。
- 修复并发上下文共享可变 CSS 的堆破坏风险；CSS 首次写入时分离存储。直接 Book 调用统一安装惰性 Windows 字体回退，避免测试顺序影响 Ruby 文本层。

## 验证证据

- [构建校验值与机器信息](evidence/iteration-0.2/builds.json)、[19 项 Release 回归日志](evidence/iteration-0.2/test-release.log)。涵盖 3 本实书 EPUB、10 份 PDF 两种模式、真实文本/图片/链接/坐标、文件释放、编码和排版、八线程 CSS 隔离。
- [窗口结果](evidence/iteration-0.2/window-scenarios.json)：四格式场景、730 项压力操作、14 项浮层与控件事件检查，以及 100/125/200% 受控 Slint 缩放；实际主机系统 DPI 150%。这些不是跨显示器与全部系统 DPI 验收。
- 旋钮事件实际改变 100% → 112% → 约 140%；拖动进度进入第 23–24 页，右键拖动改变切片原点，点击旋钮恢复适页。浮层显隐前后视区保持 1148×840 逻辑像素。原生 Winit 全屏进入/退出均检查；[实际 Windows F11 输入观察](evidence/iteration-0.2/manual-input.json)单列，用户介入后停止键鼠操作。
- [内存原始记录](evidence/iteration-0.2/memory-raw.json)、[实书 PDF 内存](evidence/iteration-0.2/pdf-real-memory.json)、[200 次暖首屏](evidence/iteration-0.2/startup-raw.json)，结论与口径见 [性能报告](performance-report.md)。生产版没有诊断轮询；独立 QA 版的 25ms 采样不参与生产内存测量。
- [浮层与排版截图](visual-qa.md)、[兼容性逐项矩阵](epub-compatibility-matrix.md)。公开图片只使用原创 CC0 样本，用户书籍和阅读记录未进入仓库或发行包。

## 未完成与风险

不能宣称 Phase 0–5 全项通过。EPUB P0 的外链确认、完整脚注/回链、宽表交互、出版方样式入口与多阅读器互操作仍有验收缺口。竖排实际仍为横排；复杂 MathML、混合固定画布、出版方跨页规则、完整 RTL/禁则等未全面兼容。

内存报告同时提供 Private Bytes、Private Working Set 与总 Working Set；映射字体仍占物理内存。最终版正文利用更多窗口面积，与旧版相同外窗并不代表排版面积相同。暖首屏计时从 main 到原生软件渲染器快照，不是冷启动、OS 合成首帧或交互就绪。主机未隔离后台应用，也未关闭杀毒。仍缺真正冷启动、长时泄漏、干净 Windows VM、完整无障碍和统一版面参照验收。

## 下一轮工作

竖排缺口已有 [真实窗口与技术选项](blockers.md)：优先扩展现有 MuPDF 原生流布局，保留单一分页/选择模型；另一个选项是按需 Rust 竖排模块，但会引入第二套坐标与分页语义，采用前需要架构决定。当前发行不加载替代浏览器或偷偷牺牲原文内容。

继续逐项补全 P0 互操作和样式入口、复杂 EPUB 样本、系统 DPI/键盘/无障碍路径及 G5 冷启动与干净环境验收。发行包保持预览标识，并同时交付匹配源码、AGPL 与依赖许可、更新说明、原图及 ICO。
