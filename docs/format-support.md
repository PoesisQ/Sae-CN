# 支持格式与按需处理

## AZW3 / MOBI

常规无 DRM 的 KF8/AZW3、MOBI 6，以及包含 KF7/KF8 两部分的混合文件，使用固定提交的
[libmobi](https://github.com/bfabiszewski/libmobi/tree/906274205c11944b628da1c553b255acb1af7c55)
解析二进制记录、PalmDOC / HUFF-CDIC、FDST、SKEL / FRAG、NCX、图片、字体和 CSS。
Rust 将重建资源逐项写入临时 EPUB；MuPDF 共用现有的重排、搜索、选字和链接流程。
原书只读，临时文件在关闭/切书时删除。解析树在 MuPDF 打开临时文件之前释放。

未打开 Kindle 文件时不创建解析器、转换进程、解析树或转换缓存。解析库静态链接；复用
已有 zlib，没有额外 DLL、Python/Calibre 依赖或常驻服务。静态代码仍会增加少量 EXE
体积，最终体积和实际内存见本轮性能报告，不能称为零开销。

边界：输入最多 96 MiB，记录最多 20,000；解析器自有分配（包含分配头）最多 96 MiB；
单项输出最多 32 MiB，总输出最多 128 MiB，生成包继续经过 EPUB 的结构/资源检查。
达到上限时显示错误，不截断正文。原生引擎、字体、zlib 内部状态和页面缓存不包含在
96 MiB 解析器分配预算内；它不是整个进程的内存上限。

DRM 在解析前检测并拒绝，解密功能未编译。KFX、AZW4、Kindle 专用交互/字典界面、
音视频播放及所有 Kindle 固定版式变种不在本轮完整兼容承诺内。音视频资源如存在则保留，
仅提示静态阅读。Ruby / MathML 等仍受现有 EPUB 兼容矩阵约束。

## FB2

继续使用已经编译的 MuPDF 原生 FictionBook 读取器，保留 FB2 标记、内嵌 base64 图片、
表格、强调、注释、链接和作者样式；不另加 XML/图像运行时。Rust 验证 XML、读取章节
标题，必要时向临时 FB2 补齐章节 ID，并严格转成 UTF-8。支持 UTF-8、UTF-16 BOM 和
声明的 `windows-1251` 等 encoding_rs 支持的编码；损坏编码不会静默替换。

输入/解码结果各最多 32 MiB，XML 最多 300,000 节点、128 层，ID 最多 10,000 个，
目录最多 5,000 项。拒绝实体声明、脚本和外部图片。XML 树只在打开时存在。
FB2 的字号、行距、字体、边距变化通过工作线程重新解析实际 CSS；窗口大小变化只重排。
原生 HTML/FB2 同样保存源文本流序号，避免将页码当作重排后的持久位置。

FB2 的页面背景通过原生 `@page` 样式覆盖页边，正文与页边使用同一主题；不逐像素
反色图片。三种主题的页面角落及原图片颜色有回归。表格文字/单元格保留，但原生自动
列宽会使部分短单元格紧缩换行；宽表、跨页表格和全部出版方样式仍需对照验收。

## 阅读界面

缩放圆盘由原生几何图形绘制。每翻倍转动 270°，拖动时直接跟随；滚轮后只有 110ms 的
缓出动画。整页与铺满视区使用不同几何比例，并随单/双页和窗口重新计算。吸附使用有界
的对数域状态，微小输入先表现为阻尼，再进入停靠区；继续操作会脱离。
画面缩放采用 80ms 单次节流，只提交最新请求；排版参数仍使用 150ms 防抖。
停止输入后没有弹簧模拟、固定帧率循环或持续动画计时器。

目录使用系统 Microsoft YaHei / Segoe UI，左对齐和实际层级缩进；长标题完整换行，行高
跟随内容，滚动条使用独立留白。列表只创建视区附近的行；保留键盘焦点和所选导航项。
没有下载或随包附带新字体。目录、查找、设置互斥，避免窄窗口中叠在一起。

阅读时左右键与 PageUp/Down 优先交给翻页，双页一次切换两页；切换模式或关闭目录、
搜索后恢复阅读焦点。上下键在适页时翻页，放大 PDF 后平移。搜索框的左右键仍移动
输入光标，排版输入与滑块保留自己的按键行为。
