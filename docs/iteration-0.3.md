# 0.3 预览版开发与验收记录 · 2026-10-27

本轮加入按需使用的 AZW3/KF8、MOBI、FB2，重做缩放圆盘，修复长目录裁切和双页方向键。
保持 Rust + Slint 软件渲染 + 原生 MuPDF；没有新增浏览器、转换进程、DLL 或常驻服务。

## 格式与资源

Kindle 使用固定提交的 libmobi 重建资源，Rust 逐项写临时 EPUB，随后复用原生重排、
选字、链接与全文搜索。C 解析树在 MuPDF 打开之前全部释放；未使用 Kindle 格式时
不创建解析器或转换缓存。复用已有 zlib，Cargo.lock 没有新增 registry 包。

FB2 使用已有原生 FictionBook 处理器。Rust 检查结构、严格解码并读取章节；仅在缺少
章节 ID 或需要转码时写临时副本，原书保持只读。MuPDF 在解析 FB2 时计算 CSS，故
字号、行距、字体、边距变化在文档工作线程重新解析，窗口变化只重排。原生 HTML/FB2
新增源文本流序号锚点，重排/重开不用绝对页码代替阅读位置。

资源上限、DRM/KFX/固定 Kindle 版式的边界见 [格式支持](format-support.md)。原生解析
尚不能在单次 C 调用中抢占；FB2 改样式时旧树与替换树可短暂并存。拒绝超限文件，
不截断正文或移除图片。临时文档随正常关闭删除，强制终止后的残留限制继续保留。

## 圆盘、目录与键盘

圆盘的指针用 Slint 几何直接绘制，沿圆周拖动会跟随转动，数值区可横向/纵向拖动。
滚轮输入只有 110ms 缓出；整页与铺满依据当前单页/双页列尺寸计算，在对数空间加入
阻尼、吸附和脱离阈值。80ms 单次节流只提交最新缩放，不运行持续弹簧模拟或空闲时钟。
修复旧渲染结果覆盖新平移输入的竞争；继续保留可见区域渲染与 16 MiB 位图缓存。

启动分段测量定位到每次命令行打开都固定等待 100ms。改为核对 Winit 实际客户区与
Slint 视区/有效 DPI；吻合时下一次事件投递立即读取，未就绪才保留原单次延迟。
优化前的二进制与测量记录保留，最终程序另行复测，避免只引用修改前数据。

目录使用系统 Segoe UI / Microsoft YaHei，左对齐、正常字重与真实层级缩进。长标题
完整换行，行高随内容增大，滚动条有独立留白；列表只创建可见行附近的控件。面板裁剪
边界明确，目录、搜索、设置互斥；浮层不会压缩正文或触发重新分页。

阅读时左右方向键和 PageUp/Down 在控件收到按键前处理，双页一次切换两页。单双页
按钮与正文点击恢复阅读焦点，关闭目录/搜索后也能继续翻页。适页时上下键翻页；PDF
放大后上下键平移。搜索框保留光标键，排版输入和滑块保留自己的按键行为。

## 已取得的窗口证据

- [窗口回归](evidence/iteration-0.3/window-scenarios.json)：12 组、981 项操作，包含
  111 项 PDF/EPUB/KF8/FB2 的按键、焦点、单/双页、全屏及窄窗口检查，75 项缩放停靠
  和圆周拖动，14 项浮层/拖动事件，23 项原有功能回归，730 项连续翻页/排版/缩放/切书。
- [长目录与控件截图](visual-qa.md)：55 项中英文目录，浅色/深色、滚动、640×480
  窄窗口；真实主机为 150% DPI，100/125/200% 是同一真实窗口中的受控 Slint 缩放，
  不冒充系统设置或跨显示器验收。
- [真实 Windows 按键](evidence/iteration-0.3/manual-input.json)：启动优化前的 0.3 普通发行构建从
  PDF 1–2 页按右键到 3–4，再按左键返回；F11 进入全屏、Esc 恢复窗口与同一跨页。
  后续文件对话框状态改变时停止 OS 输入。最终构建再次验证同一按键路径，使用程序内
  Slint 事件与原生绘制；两次构建的校验值分开记录。
- 730 项操作的私有内存从 23,752,704 B 到 27,205,632 B，句柄从 238 到 240；
  最大位图缓存 16,411,520 B，低于 16 MiB 预算。这是短时压力记录，不是长期无泄漏证明。

## 发行与未通过的闸门

Windows 包提供程序、说明与完整许可；历史截图和原始测量放在完整对应源码 ZIP，
文档链接使用该版本仓库地址。完整源码同时包含修改过的 MuPDF、libmobi、C 桥接与
有界分配器、580 个锁定 registry 包、构建与重建步骤；许可清单包括 AGPL/GPL/LGPL。
图标继续提供用户原 PNG 与多尺寸 ICO。

这是预览版。Phase 0–5 尚未全项通过：完整竖排、复杂 MathML、混合固定画布、出版方
跨页规则、完整样式优先级入口、无障碍、干净 Windows VM、真正冷启动与 OS 交互首帧
仍未验收。已知原生障碍与选项继续记录在 [blockers.md](blockers.md)，不替换技术路线。
